# 仕様: 支出予定タブ

実装: `mobile/app/(tabs)/planned-expenditures.tsx` ／ 共通規則は [spec-common.md](spec-common.md)

これから出ていく支出を登録しておく画面。2 種類ある。

| 種別 | 性質 | 完了 | 編集 | 停止/再開 |
| --- | --- | --- | --- | --- |
| 🔄 サブスク | 継続（毎月 / 毎年） | なし | 金額・課金日のみ | あり |
| 📅 カレンダー連動 | 単発（カレンダーの予定に紐づく） | あり | なし | なし |

## 画面要素

| 要素 | 内容 |
| --- | --- |
| 月ナビ | `‹ YYYY年M月 ›`。画面ローカルの `viewMonth`。未来月の制限なし |
| サマリー | 「YYYY年M月の予定支出合計」= **`is_active` のみ**の合計。「🔄 サブスク N 件 · 📅 カレンダー N 件」（件数は `is_active` を無視して全件） |
| 追加ボタン | 「＋ 予定支出を追加」→ 追加モーダル |
| 行 | 🔄/📅 ＋ 名称 ＋「予定」バッジ / カテゴリ・支払方法・請求（「毎月 N 日」「毎年 M 月 D 日」「MM/DD」）/ メモ / 金額 |
| 非アクティブ行 | 薄い表示。ボタンは種別に応じて「停止・再開」「編集」「完了」「削除」 |
| 空状態 | 📆「予定された支出を追加しましょう」 |

## 追加モーダル

タイプを「🔄 サブスク」「📅 カレンダー連動」で切り替える。

- **サブスク**: サービス名 / 金額 / カテゴリ（既定「その他」）/ 支払（現金・カード・QR、既定カード）/
  請求サイクル（毎月・毎年、既定毎月）/ 課金月（毎年のみ必須、1-12）/ 課金日（1-31）/ メモ（任意）
- **カレンダー連動**: 表示月の今後のイベントから1件選択（再タップで解除）/ 金額 /
  カテゴリ（既定その他）/ 支払（既定現金）/ メモ（任意）。イベントが無いときは
  「YYYY年M月の今後のイベントがありません」

編集モーダルは金額と課金日だけ変更できる（サービス名は表示のみ）。
完了・削除は確認アラートを出す。入力エラーと保存失敗はいずれもアラート。

## 操作

| 操作 | 結果 |
| --- | --- |
| 月ナビ | `viewMonth` 変更 → `fetchPlannedExpenditures(viewMonth)` |
| 停止 / 再開 | `PATCH` `{is_active}` |
| 編集 | 金額・課金日を `PATCH` |
| 完了（カレンダー連動のみ） | 確認 → `POST /planned-expenditures/:id/complete`。履歴へ移る |
| 削除 | 確認 → `DELETE` |
| 追加成功後 | force 取得してモーダルを閉じる |

長押し・行スワイプは無い（タブ間スワイプのみ）。

## 使う API

| API | 用途 |
| --- | --- |
| `GET /planned-expenditures?month=表示月` | 一覧 |
| `POST /planned-expenditures` | 追加 |
| `PATCH /planned-expenditures/:id` | 停止・再開・編集 |
| `POST /planned-expenditures/:id/complete` | 完了 |
| `DELETE /planned-expenditures/:id` | 削除 |
| `GET /calendar-events?month=表示月`（`X-Google-Access-Token` 必須） | 追加フォームのイベント候補 |

バックエンドが返す対象: サブスクの `monthly` は常時、`yearly` は `billing_month`
が一致する月のみ、カレンダー連動は `event_date` がその月に入るもの。

## 前提・既知の挙動

- **支出予定は月ごとに保持されない。**単一配列を上書きする。配列がどの月の内容かは
  `plannedExpendituresMonth` に持っていて、別の月を要求されたら鮮度判定を無視して取り直す
- 合計はタブ・ホーム・バックエンドの一覧のいずれも `is_active` のものだけを数える。
  件数表示だけは停止中も含む全件
- 「今後のイベント」の判定は UTC 日付基準。JST の 0〜9 時台は前日扱いになる
- 「完了」はカレンダー連動だけ。サブスクには完了が無い
- **停止したサブスクは一覧から消え、UI からは再開できない。**バックエンドの一覧が
  `is_active=false` のサブスクを除くため、次の取得で行ごと見えなくなる。「再開」ボタンと
  非アクティブ行のスタイルは、停止してから再取得するまでの間しか出てこない
  （2026-10-21 にエミュレーターで確認）
