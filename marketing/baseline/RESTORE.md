# 復元用メモ（LP撮影で設定を一時変更するとき）

LP用のスクショを撮るとき、時給設定だけ一時的に上げる。
実データのままだと「今月あと −¥2,424」のように負になり、
「あと −2,424円使える」は日本語として成立しないため。

**変更するのは時給だけ。** 支出・予定支出・シフト（Googleカレンダー）には触らない。
設定値ひとつで済むので確実に戻せる、というのがこのやり方を選んだ理由。

## 手順

1. **変更前に、いまの値を下の表に控える**
2. シフトタブ → ⚙️ で時給を上げる
   - **保存ボタンはキーボードを閉じてから押す。** 開いたままだと
     ボタンが下にずれていて（y=1344 → 1218）タップが空振りする。
     「保存しました」のダイアログが出るまでは保存されていない
3. 撮影（`README.md` の手順へ）
4. 控えた値に戻す
5. **ホーム画面が元の数値に戻ったことを確認する。** ここまでで復元完了

## 控え

| 項目 | 元の値 |
|---|---|
| 時給 | （撮影前にここへ記入） |
| シフト検出キーワード | 触らないなら記入不要 |

> **実際の値を書いたままコミットしないこと。** 時給は個人の情報で、
> このリポジトリは public。撮影が終わって復元を確認したら、
> この欄は空に戻す。
