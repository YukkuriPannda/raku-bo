# 仕様: 履歴タブ

実装: `mobile/app/(tabs)/history.tsx` ／ 共通規則は [spec-common.md](spec-common.md)

月ごとの支出一覧。閲覧・編集・削除・建て替えの返済管理をここで行う。

## 画面要素

| 要素 | 内容 |
| --- | --- |
| 月バー | `‹ YYYY年M月 （N 件） ›`。`›` は当月で無効（未来月へは行けない） |
| カテゴリチップ | 「すべて」＋ 固定カテゴリ ＋ その月に出てきたカスタムカテゴリ。横スクロール |
| 未回収バー | 表示中の月・カテゴリの `is_advance && !settled_at` の合計。0 のとき非表示 |
| 行 | 絵文字 / `store_name ?? category` / 「カテゴリ · 支払方法 · MM/DD」＋明細があれば 🧾件数 / 金額 |
| 建て替え行 | 「🤝 建て替え・未返済」または「返済済み」。未返済の金額はオレンジ |
| 空状態 | 📭「YYYY年M月の支出記録はありません」。絞り込み中は「…の「カテゴリ」の記録はありません」 |

未回収バーは当月固定のホームの `balance` を使わず、表示中の月から自前で集計する。

## 操作

| 操作 | 結果 |
| --- | --- |
| 行タップ | 明細の開閉。明細が無ければ「商品情報なし」 |
| 行の長押し（400ms） | `/screens/manual-entry` に `transactionId` を渡して編集。見つからなければアラートで戻る |
| 行を左スワイプ → 削除 | 確認アラート → `deleteTransaction`。失敗時「削除に失敗しました」 |
| 建て替え行を右スワイプ | 「返済済み」/「未返済に戻す」→ `settleAdvance` |
| 月バーの `‹` `›` | 月切替。`fetchTransactions(month)` |
| 月バーの左右スワイプ | タブ切替（行スワイプと衝突するため月バー限定） |
| プルリフレッシュ | 表示中の月を force 取得 |

支出の詳細画面は無い。編集は手動入力画面を使い回す。

## 使う API

| API | 用途 |
| --- | --- |
| `GET /transactions?month=選択月` | 一覧 |
| `DELETE /transactions/:id` | 削除 |
| `PATCH /transactions/:id` `{settled_at}` | 建て替えの返済トグル |

## 前提・制約

- 取引は月ごとに `transactionsByMonth` で保持し、今月分だけ残額計算に反映する。
  過去月を見ても残額は変わらない
- 未来月には遷移できない
- **過去月の行も編集・削除できる**（編集は全月のキャッシュから対象を探す）
- カテゴリ絞り込みは表示中の月のメモリ上で行い、通信しない
