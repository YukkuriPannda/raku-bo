# 仕様: シフトタブ

実装: `mobile/app/(tabs)/shifts.tsx` ／ 共通規則は [spec-common.md](spec-common.md)

Google カレンダーのシフトから今月の月収見込みを出す画面。設定（時給・キーワード・
ログアウト）もここに置いてある。

## 画面要素

| 要素 | 内容 |
| --- | --- |
| エラーバナー | `calendarError` があるとき表示。文言 ＋「（エラーコード: …）」。✕ で消す |
| 見込みカード | 「今月の月収見込み」`income_forecast`、「シフト N 件 · 合計 X.X 時間」、右上に ⚙️ |
| セクション見出し | 「シフト一覧 (N 件)」 |
| 行 | タイトル（1行省略）/「📅 MM/DD HH:mm 〜 MM/DD HH:mm」/「⏱ X.X 時間」/ `estimated_wage` |
| 空状態 | 📅「今月のシフトはありません」＋「Google カレンダーのシフトを読み込みます」 |

## 設定モーダル（⚙️ から）

| 項目 | 挙動 |
| --- | --- |
| 時給 | 数値入力 → 保存。0以下・非数はアラート。保存で全シフトの `estimated_wage` を再計算 |
| シフト検出キーワード | 複数行入力、1行1語、空行は除去。0件はエラー |
| ログアウト | 確認アラート → `logout()` |

## 操作

- フォーカス時に `fetchShifts(今月)`、設定欄の値を現在値で初期化
- プルリフレッシュで force 取得
- **月の切り替えは無い**（当月固定）

## 使う API

| API | 用途 |
| --- | --- |
| `GET /shifts?month=今月`（`X-Google-Access-Token` 必須） | シフト一覧 |
| `GET /profile` | 時給・キーワードの読み込み（起動時のみ） |
| `PATCH /profile` `{hourly_wage}` / `{shift_keywords}` | 設定の保存 |

## 前提・既知の挙動

- **シフトは DB に無い。**毎回 Google カレンダーから取得する。保存はしない
- `estimated_wage` はサーバが返さなければ `round(時間 × 時給)` で補完する
- キーワードの保存時は鮮度判定を無視してシフトを取り直す（キーワードが抽出条件そのものなので）
- 時給保存時の `PATCH /profile` が失敗しても画面には出ない
