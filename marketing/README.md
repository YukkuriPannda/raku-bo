# marketing/

Twitter用のLP画像を作るところ。アプリ本体のビルドとは無関係で、
`mobile/` や `backend/` からは参照されない。

```
node lp.mjs    → out/lp.png（2400x1350 / 16:9）
```

## 中身

| | |
|---|---|
| `lp.mjs` | LP画像を組み立てて書き出す |
| `mask.py` | スクショ内の固有名にモザイクをかける（後述） |
| `real/*.png` | エミュレーターから撮った**実際のアプリ画面**（無加工） |
| `real/*.masked.png` | `mask.py` の出力。lp.mjs はこちらを読む |
| `real/receipt.jpg` | 実物のレシート写真（モザイク済み。後述） |
| `out/` | 生成物。gitignore 済み（作り直せるので置かない） |
| `baseline/RESTORE.md` | 撮影時に一時変更した設定の**元の値** |

## なぜ Playwright なのか

**この環境ではヘッドレスChromeが動かない。** 起動中のChromeに吸われて
「既存のブラウザセッションで開いています」となり、`--user-data-dir` を
分けても Git Bash / PowerShell どちらからも何も出力しない。
Playwright は自前のChromiumを持つので影響を受けない。

`convert` コマンドは存在するが **ImageMagickではなく Windows標準の
FAT→NTFS変換ツール**（`C:\WINDOWS\system32\convert.exe`）。画像処理に
使ってはいけない。加工は Pillow を使うこと。

## 画面を撮り直す手順

1. エミュレーターでアプリを開く
2. **時給設定を一時的に上げる**（シフトタブ → ⚙️）
   実データのままだと「今月あと **−¥2,424**」と負になり、
   「あと −2,424円使える」は日本語として成立しないため。
   支出・予定支出・シフト（Googleカレンダー）には触らない
   ＝ **設定値ひとつだけ**なので確実に戻せる
   - 保存ボタンはキーボードを閉じてから押すこと。開いたままだと
     ボタンの位置がずれて空振りする（y=1344 → 1218 に動く）
3. `adb shell screencap` で各タブを撮り、`real/` に置く
4. **必ず時給を `baseline/RESTORE.md` の値に戻し、ホームが元の数値に
   戻ったことを確認する**
5. `python mask.py`（固有名にモザイク。並び順が変わったら座標を取り直す）
6. `node lp.mjs`

Git Bash から `adb` を叩くときは `export MSYS_NO_PATHCONV=1` を先に実行する。
付けないと `/sdcard/s.xml` が `C:/Program Files/Git/sdcard/s.xml` に化ける。

## レシート画像について

カメラ画面だけは合成している。エミュレーターの仮想カメラは
「架空の部屋とテストパターン」しか映せず、レシートを撮っている画に
ならないため。UIの作りは実機と同じものを再現し、ファインダーの中身だけ
実物のレシート写真に差し替えている。

**モザイクをかけている箇所**（`lp.mjs` のコメント参照）:
会員No（下4桁）/ 有効期限 / お取扱日 / 支払方法 / 承認番号 / 処理通番 / AID。

レシート幅で横に切ると縦横比が 0.452 になり、端末画面（0.45）にほぼ
そのまま収まる。**上部だけ切り出す方法は使えない** — 縦が足りず、
`object-fit: cover` で必ず文字が左右に切れる。

## 公開前に確認すること

写っているのは**本人の実データ**である。バイト先やイベントの名前が
そのまま出るため、`mask.py` でモザイクをかけている。

マスク対象は `mask.py` の `TARGETS` に**座標と文字数だけ**で持たせている。
**固有名そのものをソースに書かないこと** — このリポジトリは public なので、
隠す対象をコードに書いたら隠した意味がなくなる。

現在マスクしていないもの: 予定支出の一部の項目名、金額、シフトの時間帯。
時間帯からは生活パターンが読めるので、必要なら `TARGETS` に足す。

撮り直したときは、マスク対象が漏れていないか投稿前に必ず目視で確認する。
