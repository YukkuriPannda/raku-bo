# 仕様: 残額ウィジェット

実装: `mobile/widgets/RemainingBudgetWidget.tsx`（登録名 `RemainingBudget`）
共通の仕組みは [spec-widget-common.md](spec-widget-common.md)

ホーム画面で「今月あと○○円」を見せる 2×2 のウィジェット。
中身はホームタブの要約（[spec-home.md](spec-home.md)）。

## 表示要素（上から）

| 要素 | 内容 |
| --- | --- |
| ラベル | 「今月あと」9sp / `#6b7280` |
| 金額 | 18sp bold。`¥` + `toLocaleString('ja-JP')`。0以上は緑 `#22c55e`、負は赤 `#ef4444` |
| 下段ラベル | 0以上なら「使える」、負なら「つかいすぎ」 |
| 🤝 未回収 | 未回収の建て替えが 0 より大きいときだけ 1 行。`#E65100` |
| 直近の支出 | 最大2件。店名（なければカテゴリ、1行で末尾省略）と金額 |
| 直近の支出予定 | 最大2件。ラベル `#f59e0b` / 金額 `#E65100` |
| 撮影ボタン | 「📷 レシートを撮影」。背景 `#1B7F4F` |

背景は白 `#ffffff` の角丸16。色はすべて hex 直書きで、テーマトークンは参照しない。

**データが無いとき**（初回・ログアウト後・読み出し失敗）は金額が `¥ ---`（`#9ca3af`）、
下段が **「ひらいて更新」** になり、未回収行とリストは出ない。

## タップ

| 対象 | 動作 |
| --- | --- |
| ウィジェット全体 | `OPEN_APP` — アプリを起動する |
| 撮影ボタン | `OPEN_URI` — `rakubo://screens/camera` を開く |

どちらもネイティブで完結し、JS は動かない。未ログインなら起動後に
ログイン画面へ飛ばされる（`app/_layout.tsx` の認証ガード。実機未確認）。

## 保存されるデータ

`saveWidgetBudget()` が JSON で書く。

| 項目 | 元 |
| --- | --- |
| `remaining` | `calcBalance` の残額（月収見込み − 現金支出 − 予定支出合計） |
| `unsettledAdvance` | 未回収の建て替え合計 |
| `recentTransactions` | 現金かつ建て替えでない取引を日付の降順で上位2件 |
| `upcomingPlanned` | カレンダー連動の支出予定で `event_date >= 今日`（端末ローカル日付）のものを昇順で上位2件 |
| `month` / `updatedAt` | 保存するが**描画には使っていない** |

残額の定義と建て替えの扱いは [spec-common.md](spec-common.md#残額の計算) と同じ。

## 既知の挙動

- ラベル（店名・イベント名）は24文字で切ってから保存する。これで最悪でも約550バイトに収まり、
  SecureStore の 2048 バイト上限を超えない。超えた場合は警告を出す
- min と max が同じ 120dp なので、リサイズを許可していても実質固定サイズ
